# golf4-150k entry

Tiny Chess 01 entry ([make.fun bounty](https://make.fun/bounty/tiny-chess-01)). Engine in main.py (4,081 bytes, at most 4,096).

GOLF4 fitted engine with the node budget raised to 150,000 nodes per move (the only change from the GOLF4 entry). Trial-0 1,279. Fresh-draw 4-draw mean 1,346.4 (vs sunfish 1,341.4). The prize gate is a 90% paired t-interval test, not a mean comparison — a positive mean lead alone does not establish a gate pass.
